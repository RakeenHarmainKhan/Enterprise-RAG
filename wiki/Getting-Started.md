# From zero to a working RAG in one sitting

**You are about to run three moving parts**—API, index, cache—and glue them together with a single **`config.yaml`**. This page is the shortest path from clone to **`"status": "ok"`** on an upload.

> [!TIP]
> If something fails, jump to **When it hurts**—most “mysterious” issues are OpenSearch URLs, Redis pings, or missing **`OPENAI_API_KEY`**.

---

## Prerequisites

| Component | Version / notes |
|-----------|-----------------|
| Python | **3.12+** (Makefile uses `uv venv --python 3.12`) |

## Install

```bash
git clone https://github.com/anmolg1997/Enterprise-RAG-System.git
cd Enterprise-RAG-System
cp env.example .env
```

Edit **`.env`**:

- **`OPENAI_API_KEY`** — required for default chat + **`openai`** embedder.
- **`OPENSEARCH_URL`** — default **`http://localhost:9200`** for local OpenSearch.
- **`REDIS_URL`** — default **`redis://localhost:6379/0`**.
- **`LANGFUSE_*`** — optional; omit to disable remote tracing.

Install dependencies:

```bash
make setup
```

This runs **`backend-setup`** (uv venv + pip) and **`frontend-setup`** (npm install).

> [!NOTE]
> First **`make setup`** can take a minute—downloading wheels and npm trees is not a spectator sport.

## Start infrastructure

### Free local models on a Windows 16 GB laptop

This setup uses [config.laptop.yaml](../config.laptop.yaml),
[env.laptop.example](../env.laptop.example), and
[docker-compose.laptop.yml](../docker-compose.laptop.yml).
It does not change the original OpenAI configuration. The backend, frontend,
and Ollama run on Windows; Docker runs just one OpenSearch node and, optionally,
Redis. No OpenAI or Langfuse credentials are needed.

**Transfer the source, not the installed environment.** Copy the project source,
including these three laptop files and the backend fixes. Do not copy `.env`,
`rag-env`, `frontend\node_modules`, `uploads`, `logs`, or Python caches.
Virtual environments contain machine-specific paths and must be recreated.
Re-upload the original documents after setup rather than copying registry files
that contain paths from this computer.

Install:

- Python **3.12**, with the Windows Python launcher (`py`).
- Node.js **22 LTS** or **24 LTS**.
- [Docker Desktop](https://docs.docker.com/desktop/setup/install/windows-install/)
  with its **WSL 2 backend** and **Linux containers**. Start Docker Desktop.
- [Ollama for Windows](https://docs.ollama.com/windows). Keep its local server
  running at `http://localhost:11434`; do not expose it to the network.

Allow at least **20 GB free disk** for environments, images, model downloads and
documents. More may be needed as your collection grows. With 16 GB RAM, close
unused applications. The original cross-encoder reranker and hallucination
checker remain enabled at your request; they add memory and CPU overhead.
A dedicated GPU is optional, but CPU-only queries may be slow.

#### 1. Recreate dependencies on the laptop

Open PowerShell in the copied project root. On a fresh copy without `.env`:

```powershell
# Generated by GitHub Copilot - Nov-01-2026
Copy-Item env.laptop.example .env
py -3.12 -m venv rag-env
.\rag-env\Scripts\python.exe -m pip install -r backend\requirements.txt
.\rag-env\Scripts\python.exe -m pip check
Set-Location frontend
npm ci
Set-Location ..
```

Do not overwrite an existing `.env` containing credentials without backing it
up first. The laptop template explicitly selects `ollama_chat`, because
environment LLM settings override the YAML provider and model.

#### 2. Download and verify Ollama's small chat model

```powershell
# Generated by GitHub Copilot - Nov-01-2026
ollama pull qwen2.5:1.5b
ollama run qwen2.5:1.5b "Reply with one short greeting."
Invoke-RestMethod http://localhost:11434/api/tags
```

The 1.5B model is a resource-conscious starting point, not an enterprise-quality
answer guarantee. Its answers and citations must be checked against documents.
MiniLM embeddings, the reranker, and the hallucination checker download from
Hugging Face on first use. Initial setup requires internet; once those models
are cached, document embeddings and chat run locally without API charges.

To finish downloads **before** using the UI, run these from the project root.
Each command exits before the next loads a model, reducing peak memory use:

```powershell
# Generated by GitHub Copilot - Nov-06-2026
.\rag-env\Scripts\python.exe -c "from sentence_transformers import SentenceTransformer; m = SentenceTransformer('all-MiniLM-L6-v2'); print('Embedding dimensions:', m.get_sentence_embedding_dimension())"
.\rag-env\Scripts\python.exe -c "from sentence_transformers import CrossEncoder; CrossEncoder('cross-encoder/ms-marco-MiniLM-L-6-v2'); print('Reranker ready')"
.\rag-env\Scripts\python.exe -c "from sentence_transformers import CrossEncoder; CrossEncoder('cross-encoder/nli-deberta-v3-small'); print('Hallucination checker ready')"
```

Expect `Embedding dimensions: 384`. Do not continue if a download fails;
resolve the terminal error first. The default Hugging Face cache is in your
Windows user profile, outside this project. A cache from another machine is
not included in the source ZIP.

#### 3. Start OpenSearch

```powershell
# Generated by GitHub Copilot - Nov-01-2026
docker compose -f docker-compose.laptop.yml config --quiet
docker compose -f docker-compose.laptop.yml up -d --wait --wait-timeout 300
Invoke-RestMethod http://127.0.0.1:9200
```

Only OpenSearch starts by default. This file is independent of the original
two-node Compose setup: **do not use plain `docker compose up` for this profile**.
Host ports bind only to `127.0.0.1`. OpenSearch security is disabled for local
learning, so do not use this setup for sensitive or shared data. Do not run the
native Windows OpenSearch node on port 9200 at the same time.

If OpenSearch fails with a `vm.max_map_count` bootstrap error, inspect its logs:

```powershell
# Generated by GitHub Copilot - Nov-01-2026
docker compose -f docker-compose.laptop.yml logs --tail 100 opensearch
```

For Docker Desktop's WSL backend, the temporary host adjustment is:

```powershell
# Generated by GitHub Copilot - Nov-01-2026
wsl -d docker-desktop -u root -- sysctl -w vm.max_map_count=262144
docker compose -f docker-compose.laptop.yml up -d --wait --wait-timeout 300
```

Apply this only if the error occurs. It may need reapplying after Docker/WSL
restarts; follow Docker Desktop's documentation if the distribution is unavailable.

#### 4. Start the backend and frontend

Terminal 1, from the project root:

```powershell
# Generated by GitHub Copilot - Nov-01-2026
.\rag-env\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
```

Terminal 2, from the project root:

```powershell
# Generated by GitHub Copilot - Nov-01-2026
Set-Location frontend
npm run dev -- --host 127.0.0.1 --strictPort
```

Terminal 3:

```powershell
# Generated by GitHub Copilot - Nov-01-2026
Invoke-RestMethod http://127.0.0.1:8000/health/ready | ConvertTo-Json -Depth 5
Invoke-RestMethod http://127.0.0.1:8000/admin/config | ConvertTo-Json -Depth 8
```

Confirm `ready: true`, `redis.enabled: false`, `llm.provider: ollama_chat`,
and `ingestion.embedder: local`. Open `http://127.0.0.1:5173`.
Readiness checks OpenSearch and, when enabled, Redis; it does **not** check
Ollama, model downloads, or answer quality. The upload and query checks below
are required before considering the laptop setup verified.
Upload one short, non-sensitive PDF or DOCX and verify its status becomes
`ready` with more than zero chunks. Then ask a short question about that document.
Leave the original files available for re-upload.

For the first verification, **uncheck Stream (SSE)** in Chat: the non-streaming
response includes structured sources for the Sources panel. The existing
streaming response does not send structured sources, and the UI does not
display guardrail warnings. Verify important answers against the document;
the hallucination checker is configured to warn, not block.

The laptop profile uses a **new index name** for MiniLM's **384-dimensional**
vectors. Do not reuse an OpenAI embedding index or mix vectors from different
models. First uploads/queries can trigger model downloads and exceed the UI's
120-second request timeout. Let backend work finish, check status with Refresh,
and read backend errors before uploading duplicates. Retry the query after
downloads finish. Short questions and a smaller context budget reduce CPU work.

#### 5. Optional Redis, after ingestion and chat work

Redis is free locally and is included as an optional service:

```powershell
# Generated by GitHub Copilot - Nov-01-2026
docker compose -f docker-compose.laptop.yml --profile cache up -d --wait --wait-timeout 300
docker compose -f docker-compose.laptop.yml exec redis redis-cli ping
```

Expected response: `PONG`. This starts Redis but does not enable caching.
To enable it, change `cache.backend` in `config.laptop.yaml` from `none` to
`redis`, then restart the backend. Readiness will now require Redis.

**Cache limitation:** the existing semantic cache is not scoped to a collection
and does not invalidate entries when documents change. Leave it disabled for
multiple collections or changing documents. For a single-collection learning
demo, restart with a new Redis database number in `REDIS_URL` after document
changes to avoid reusing stale answers. The `ttl_seconds` setting is an expiry,
not a guarantee that cached answers match your current documents.

#### Stop safely

Stop backend/frontend terminals with **Ctrl+C**. Stop the infrastructure:

```powershell
# Generated by GitHub Copilot - Nov-01-2026
docker compose -f docker-compose.laptop.yml --profile cache stop
ollama stop qwen2.5:1.5b
```

OpenSearch and Redis data remain in Docker volumes. Do not use `down -v` unless
you intentionally want to delete indexed data and cache data.

**Option A — Docker Compose (recommended):**

```bash
docker compose up -d
```

Waits for healthy OpenSearch nodes and Redis, then starts backend (port **8000**) and frontend (**5173**).

**Option B — Local OpenSearch + Redis only:**

```bash
docker compose up -d opensearch-node1 opensearch-node2 redis opensearch-dashboards
```

Run API + UI with **`make dev`** from host.

## Start application (local dev)

### Windows without Docker or Redis

Install the official [OpenSearch 2.19 Windows ZIP](https://docs.opensearch.org/2.19/install-and-configure/install-opensearch/windows/).
The archive includes Java. Use an extraction path without spaces. OpenSearch is
required for ingestion and retrieval; installing `opensearch-py` only installs
the Python client, not the server. OpenSearch Dashboards is optional.

For an isolated, local learning setup, add these settings to the extracted
OpenSearch `config\opensearch.yml`:

```yaml
# Generated by GitHub Copilot - Nov-01-2026
network.host: 127.0.0.1
discovery.type: single-node
plugins.security.disabled: true
action.destructive_requires_name: true
```

**Never expose this security-disabled node to a network or use it for sensitive
documents.** Shared deployments require authentication and trusted TLS.

On a memory-constrained development machine, change the existing `-Xms1g` and
`-Xmx1g` entries in OpenSearch `config\jvm.options` to `-Xms512m` and `-Xmx512m`.
OpenSearch uses additional native memory beyond its Java heap.

From the extracted OpenSearch directory, start it in a separate PowerShell terminal:

```powershell
# Generated by GitHub Copilot - Nov-01-2026
.\bin\opensearch.bat
```

In the project's `.env`, use `OPENSEARCH_URL=http://127.0.0.1:9200`.
For this security-disabled node, leave `OPENSEARCH_USER` and
`OPENSEARCH_PASSWORD` empty. Keep your OpenAI API key in `.env`, not in source
code. To run without Redis, set `cache.backend: none` in `config.yaml`.
Queries bypass the cache and readiness skips the Redis check. The Redis Python
package is still imported, so leave it installed.

With an existing `rag-env`, run the backend **from the project root**:

```powershell
# Generated by GitHub Copilot - Nov-01-2026
.\rag-env\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
```

In another PowerShell terminal, from the project root:

```powershell
# Generated by GitHub Copilot - Nov-01-2026
Set-Location frontend
npm run dev -- --host 127.0.0.1
```

Verify `http://127.0.0.1:9200`, `http://127.0.0.1:8000/health/ready`,
and `http://127.0.0.1:5173`. Stop each foreground service with **Ctrl+C**.
The index is created on the first successful ingestion; an unused single-node
index can report yellow health because replica shards require another node.

### Makefile-based startup

From repo root (so **`config.yaml`** resolves):

```bash
make dev
```

- API: http://localhost:8000/docs  
- UI: http://localhost:5173  

Single process:

```bash

make frontend   # terminal 2
```

> [!IMPORTANT]
> Run **`make backend`** from the **repository root** via the Makefile so **`config.yaml`** resolves the way the **`backend`** target expects.

## First document upload

Using curl:

```bash
curl -sS -X POST http://localhost:8000/documents/upload \
  -F "file=@./your-document.pdf" | python3 -m json.tool
```

Or use the **DocumentManager** component in the UI.

Wait for **`"status": "ok"`** and note **`document_id`** and **`chunks`**.

Example shape (values vary):

```json
{
  "status": "ok",
  "document_id": "…",
  "chunks": 42,
  "indexed": 42,
  "filename": "your-document.pdf",
  "collection_id": "default"
}
```

## First query

```bash
curl -sS -X POST http://localhost:8000/query \
  -H "Content-Type: application/json" \
  -d '{"query":"Summarize the main points from the uploaded document.","stream":false}' \
  | python3 -m json.tool
```

If guardrails block, response is **400** with **`detail.blocked`**.

## Docker setup notes

- Backend receives **`CONFIG_YAML_PATH=/app/config.yaml`** and a read-only mount of **`./config.yaml`**.
- Uploads persist in the **`uploads_data`** volume.
- OpenSearch in compose uses **`DISABLE_SECURITY_PLUGIN=true`** — suitable for **local** development only.

> [!WARNING]
> **`DISABLE_SECURITY_PLUGIN=true`** is a convenience, not a security model. Do not expose that cluster to the internet.

## When it hurts (troubleshooting)

| Symptom | Check |
|---------|--------|
| `/health/ready` → `ready: false` | OpenSearch reachable at **`OPENSEARCH_URL`**? Redis **`PING`**? |
| `OPENAI_API_KEY required` | Key set in **`.env`** for embedder / LLM |
| Empty PDF text | Scanned PDFs need OCR upstream (not included) |
| Index mapping conflict | Changing embedding dimension may require new **`index_name`** or reindex |
| CORS errors in browser | Add your UI origin to **`CORS_ORIGINS`** |
| `Unknown plugin` on startup | Typo in **`config.yaml`** plugin name |
| Slow first query | Cross-encoder and sentence-transformers **lazy-load** models on first use |

```bash
make health
```
